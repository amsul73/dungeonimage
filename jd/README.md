# `jd/` — 분석용 JD 본문 보관함

사람인 공개 API 는 공고의 **JD 본문**(자격요건·우대사항 전문)을 주지 않습니다.
`jobalert scan` 으로 "이 직무가 공통적으로 뭘 요구하는지"를 보려면 본문이 필요하므로,
관심 공고 본문을 여기에 텍스트 파일로 모아 둡니다.

## 저장 방법

1. 공고 페이지에서 **주요업무 / 자격요건 / 우대사항** 부분을 그대로 복사
2. 이 폴더에 `.txt` 로 저장. 파일 이름은 `회사명_직무명.txt` 를 권장합니다.

```
jd/
  토스_프로덕트오너.txt
  당근_서비스기획자.txt
  무신사_PM.txt
```

3. 30개쯤 모이면 빈도가 안정됩니다. 10개 미만이면 참고 수준입니다.

## 파일 내용 예시

섹션 제목 줄(`자격요건`, `우대사항`, `주요업무` 등)은 그대로 두세요.
그 줄을 기준으로 섹션을 나눠 "필수 요구"와 "우대"를 구분해 집계합니다.

```
주요 업무
- 서비스 핵심 지표를 정의하고 개선 과제를 발굴합니다
- 요구사항 정의서와 화면설계서를 작성해 개발팀에 전달합니다

자격 요건
- SQL 로 직접 데이터를 추출하고 분석할 수 있는 분
- 유관 부서와의 커뮤니케이션 경험

우대 사항
- A/B 테스트 설계 및 해석 경험
- Amplitude, GA4 등 프로덕트 분석 도구 사용 경험
```

## 실행

```bash
python main.py scan --jd-dir jd --markdown 요구역량.md
```

> 이 폴더의 `.txt` 파일은 `.gitignore` 에 걸려 커밋되지 않습니다(공고 원문 보관 목적).
